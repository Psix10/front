# GigaChat Frontend Application

Полная оболочка чат-приложения с React и TypeScript для интеграции с GigaChat API.

## 🎯 Функциональность

- **Аутентификация**: Форма входа с валидацией Base64 credentials
- **Чат-интерфейс**: Рабочая область с боковой панелью и основной зоной чата
- **Сообщения**: Поддержка Markdown, работа с моковыми данными
- **Настройки**: Панель с управлением моделью, параметрами, темой
- **Адаптивность**: Мобильная версия с бургер-меню
- **Темы**: Светлая и тёмная темы через CSS-переменные

## 🚀 Установка и запуск

### Установка зависимостей
```bash
npm install
```

### Запуск dev-сервера
```bash
npm run dev
```
Приложение откроется на `http://localhost:5173/`

### Сборка для production
```bash
npm run build
```

### Preview production сборки
```bash
npm run preview
```

## 📝 Компоненты

### AuthForm
Форма входа с:
- Полем для Base64-credentials
- Радио-кнопками выбора Scope
- Валидацией на фронтенде

### Sidebar
Боковая панель с:
- Кнопкой "Новый чат"
- Поиском по чатам
- Списком чатов с кнопками редактирования/удаления
- Адаптивностью (скрывается на мобильных)

### ChatWindow
Основная область с:
- Заголовком и кнопкой настроек
- Списком сообщений с автопрокруткой
- Полем ввода с автоподстройкой высоты
- Слайдером SettingsPanel

### Message
Компонент сообщения с:
- Поддержкой Markdown через react-markdown
- Кнопкой копирования (появляется при hover)
- Разными стилями для пользователя и assistant
- Аватаром для сообщений assistant

### InputArea
Поле ввода с:
- Многострочным textarea (макс 5 строк)
- Автоподстройкой высоты
- Кнопкой отправки (активна при непустом вводе)
- Поддержкой Shift+Enter для переноса строк
- Кнопкой прикрепления файла (заглушка)

### SettingsPanel
Панель настроек с:
- Выбором модели GigaChat
- Слайдерами Temperature и Top-P
- Полем Max Tokens
- TextArea для System Prompt
- Переключателем темы
- Кнопками Сохранить и Сбросить
